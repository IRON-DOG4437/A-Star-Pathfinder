# ⭐ A* Pathfinding Algorithm

Python implementation of the A* (A-Star) algorithm to find the optimal path in a 2D grid-based maze.

## 🧠 Features

- Implements A* using Manhattan or Euclidean heuristics
- Supports obstacles and dynamic start/end positions
- Outputs the optimal path, with optional visualization or text output
- Clean code using priority queues and cost maps

## ⚙️ How to Run

```bash
python Vatsal_EE23B084_astar.py
```
